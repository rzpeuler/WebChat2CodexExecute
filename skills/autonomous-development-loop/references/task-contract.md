# Sol Task Contract

Use this contract for an approved work package in any Git repository. Sol
defines outcome and boundary; Luna chooses the implementation.

```text
TASK_ID:
TITLE:
OBJECTIVE:
WHY:
BASELINE:
CURRENT_STATE:
REQUIRED_BEHAVIOR:
SCOPE:
OUT_OF_SCOPE:
ARCHITECTURAL_DECISIONS:
IMPLEMENTATION_FREEDOM:
ACCEPTANCE_CRITERIA:
VALIDATION:
PROTECTED_CONSTRAINTS:
EXPECTED_ARTIFACTS:
KNOWN_RISKS:
BLOCKING_CONDITIONS:
```

Luna should search the repository for ordinary missing details such as file
locations and test commands. It must stop only when the missing information
would change the product or architecture materially. It may decide normal
implementation details, decomposition, debugging strategy, and focused tests.
